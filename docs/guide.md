# 使用 Atlas

[打开在线画廊](https://biletian.github.io/ai-visual-atlas-preview/) · [返回文档导航](README.md)

## 从发现到出处

1. 在画廊浏览作品，按主题或模型缩小范围，也可搜索感兴趣的内容。
2. 打开作品详情，查看图片或视频、公开提示词、模型说明和参考条件。
3. 有组图或多段视频时，继续切换查看；一组作品不等于一张图片。
4. 通过原作者或原始发布链接核对完整语境与使用条件。
5. 将喜欢的作品加入浏览器本地收藏，便于稍后再看。

## 常见问题

### Atlas 可以直接生成图片吗？
不能。Atlas 是作品收录与发现工具，不是生成服务；使用提示词仍需自行选择相应模型与工具。

### 为什么同一个提示词生成结果不同？
模型版本、随机性、参考图、参数和后期处理都可能影响结果。部分来源仅分享摘录、模板或展示效果；未公开的信息不会被补造。参考案例不等于复现保证。

### 收藏会同步到另一台设备吗？
目前收藏保存在当前浏览器，不提供账号同步。清除站点数据、更换浏览器或设备后，收藏可能不再可用。

### 为什么有些视频只看到封面？
README 使用视频封面，点击进入画廊详情查看视频。加载还会受媒体格式、浏览器播放限制与网络影响。遇到失效内容，可通过[问题报告](https://github.com/biletian/ai-visual-atlas-preview/issues/new?template=bug-report.yml)提供作品链接与浏览器版本。

### 可以下载后商用或转载吗？
收录、链接与署名不等于商用或再分发授权。请核对原始来源的许可，必要时联系权利人。详见[权属与署名说明](rights-and-attribution.md)。

### README 数量为什么可能与网站不一致？
README 标注的是某次核验快照，线上可持续更新。统计按精选作品组去重，不把候选、历史归档或一组内多张图片累加成精选数量。

### 如何推荐、纠错或请求移除？
使用[帮助入口](../SUPPORT.md)里的对应表单。请提供原始来源和具体问题；公开 Issue 不要上传证件、私人联系方式或敏感材料。
