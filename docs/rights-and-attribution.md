# 权属与署名边界

## 产品与收录作品不同

Atlas 的名称、产品说明和仓库顶部产品封面用于介绍收录工具。当前顶部封面是产品品牌图形，不是收录作品，也不声称是实际界面截图。

作品展、分类示例、视频封面及作品详情属于收录内容。每项保留作者或来源署名及原始链接，不将其视为 Atlas 原创作品或合作案例。展示中的品牌、人物与场景不代表项目的合作、背书或真实事件记录。

## 许可不能从公开可见推断

- 公开原帖、署名和链接不自动授予转载、商用、训练或再分发权利。
- 数据中的 `owner-directed-display` 是项目展示记录，不是原作者授予的开放许可证。
- 提示词也可能有独立使用条件；完整、摘录、模板和未公开状态应按来源记录区分。
- 缩略图、视频封面与转码不改变原始权属。继续使用时应回到来源核实条款。
